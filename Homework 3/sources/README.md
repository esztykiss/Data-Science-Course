# Millionaire Habits Dataset

## Overview

A large-scale synthetic dataset designed to explore relationships between wealth status,
financial habits, productivity, lifestyle, education, career, investing, business ownership,
health routines, psychology, risk tolerance, and long-term financial behavior.

**IMPORTANT: This is a SYNTHETIC dataset.** It does NOT represent real individuals or a real
millionaire survey. It was created for research, educational, exploratory data analysis,
visualization, and machine-learning experimentation.

## What's Inside?

- 100,000+ rows (unique synthetic individuals)
- 180+ columns covering demographics, education, career, entrepreneurship, wealth,
  saving, investing, debt, productivity, time management, health, psychology, social,
  lifestyle, financial behavior, habit consistency, and ML targets

## Target Variables

- millionaire_status: 1 if net worth >= $1,000,000 USD
- multi_millionaire_status: 1 if net worth >= $5,000,000 USD
- wealth_category: Categorical wealth bracket
- financial_independence_status: 1 if net worth >= 25x annual expenses
- high_saver_status: 1 if savings rate >= 20%
- high_investor_status: 1 if investment assets >= $100,000

## Synthetic Data Notice

This dataset is entirely synthetic. No real people, real names, real addresses, phone numbers,
emails, or any personally identifiable information is included.

## Data Generation

- Method: Probabilistic generation with latent factor modeling
- Seed: 20260914
- Tools: Python (NumPy, Pandas)
- Missingness: 1-5% realistic missing values
